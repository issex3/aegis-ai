# Security

## Reporting a vulnerability

If you believe you have found a security issue in this repository, please open a **private** GitHub security advisory on the repo, or email the maintainer via GitHub profile contact options.

Please do **not** open a public issue for exploitable vulnerabilities.

## Scope notes

- Local `.env`, databases, and encryption keys must never be committed.
- Sandboxes use fictional data and simulated tools only.
- Demo / simulated assessment output is labelled as such and is not evidence about a live production system.
